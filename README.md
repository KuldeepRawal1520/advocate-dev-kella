# Advocate Dev Kella Website

A responsive, single-page professional information website for Advocate Dev Sanjay Kella, based in Ahmedabad, Gujarat.

## Project structure

- `index.html` - site markup, styles and lightweight interactions
- `public/images/` - uploaded photographs and association graphics

## Run locally

No build tools are required. Open `index.html` in a browser, or serve the project with any static web server.

## Deploy with Vercel

Import this repository in Vercel as a static site. Set the root directory to the repository root and leave the build command empty. The static page is `index.html`.

## Important notes

- Verify the biography, office details, current association roles and practice areas before public launch.
- The enquiry form is currently informational only and does not transmit or store enquiries.
- Replace the placeholder email/contact functionality only after the owner confirms the correct professional email and preferred handling for personal information.
- Review the site for compliance with applicable Bar Council of India rules before publishing or promoting it.
